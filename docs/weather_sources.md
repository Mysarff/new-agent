# 天气模块：数据来源与验收

核实日期：2026-09-26。实现入口：`wayloom/weather.py`。

## 官方接口与边界

- [Open-Meteo 地点 API](https://open-meteo.com/en/docs/geocoding-api)：按任意地点名称查询；返回 GeoNames 地点 ID、国家、行政区、经纬度和时区。同名地点保留候选；不取第一名默认为用户目的地。支持 `countryCode` 两位国家筛选，以及 `地点, 省份/国家` 限定查询。
- [Open-Meteo 天气 API](https://open-meteo.com/en/docs)：`forecast` 只接受地点 ID，先通过官方 `/v1/get?id=…` 再次核实坐标和时区。按目的地当地日期支持今天至第 16 天，含今天。超过范围返回 `out_of_range`，不编造远期天气。城市名单和城市坐标均未写在业务代码中。
- 每日返回 WMO 天气码、最高/最低温度、最高降水概率、总降水量、降雨量、最大风速，以及原始单位、实际查询 URL、UTC 检索时间。总降水量包括雨、阵雨和雪水当量；`rain_sum` 另行保留，不能将其等同于总降水。数据是气象模型预报，不是现场实测，也不是政府灾害预警。
- `weather_description` 是按[官方 WMO 码表](https://open-meteo.com/en/docs#weathervariables)做的本地中文解释，与原始代码一起返回。例如 51 为轻微毛毛雨，45 才是雾；未知代码和缺测分别标为“未知”和“暂无”，不推断成晴天。码表强度用语不等于中国降水量等级或官方预警。
- 缺测保留 `null`，不视为零；所有变量缺测返回 `no_data`。API 故障返回 `error`，没有演示数据或离线天气兜底。
- Windows 运行需要 IANA 时区数据库（Python `tzdata` 包）。
- 本版使用无密钥公开端点，适合非商业原型。[官方使用额度与商业方案](https://open-meteo.com/en/pricing)应在公开部署前复核；商业服务应另接客户 API，不应把免费端点当成无限量商业服务。
